# ร้านลับแลของฝาก: หน้าฟอร์มและสคริปต์ฝั่งเซิร์ฟเวอร์ (สัปดาห์ที่ 3)

คลังตัวอย่างวิชา 3603403 ใช้คู่กับใบงานที่ 3 ร้านและข้อมูลทั้งหมดเป็นของสมมติ

| ไฟล์ | หน้าที่ | ทำงานที่ |
|---|---|---|
| `index.html` | หน้าฟอร์มสั่งซื้อ 2 แบบ (GET และ POST) | เซิร์ฟเวอร์ส่งไฟล์นี้ให้เบราว์เซอร์ตรง ๆ |
| `functions/order.js` | อ่านค่าจากฟอร์มแล้วสร้างหน้าตอบ | ทำงานบนเซิร์ฟเวอร์ของ Cloudflare เมื่อมีคำขอมาที่ `/order` |

เชื่อมคลังนี้กับ Cloudflare Pages แล้วทุกครั้งที่ `git push` เว็บจะ deploy ใหม่เอง สคริปต์ไม่ได้เก็บใบสั่ง (ยังไม่มีฐานข้อมูล)
